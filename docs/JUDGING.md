# Judging and evidence

Sources: https://www.builder.io/hackathon and https://www.builder.io/hackathon/rules (researched during intake).

- Usefulness/execution 40%: one understandable product change -> usable shareable comic, actual export.
- Creativity/design 20%: visual storytelling, expressive staged characters, readable and concise dialogue. Real human judgment required.
- Innovation 20%: person directly edits the same scene the agent works on; agent continues around that contribution.
- Cleverness/use of Agent-Native 20%: actual shared validated action layer, selection context, durable domain state, protected/stale-write behavior.

Required: functional Agent-Native app; public Clips demo without login; disclose templates/pre-existing work. Public source/deployment encouraged, not required. No invented usage/engagement metrics. Event deadline 2026-11-10 07:59 UTC (Nov 9 23:59 PT).

Proof evidence must distinguish implemented, tested, illustrative, untested and blocked. No submitted entry is authorized.
